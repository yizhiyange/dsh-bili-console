# 接入 QQ（让机器人会刷B站）

> 装完插件，机器人就能「看自己刷到了什么、按关键词搜视频、被喊一句就去野一轮」。
> 这里有三条路，挑一条就行——**都不用另装服务**，门卫是插件本体自带的。

## 30 秒接入（最短版）

1. **插件跑起来**：DSH 里装了插件就行；不用 DSH 的话用独立版 `node standalone.mjs`（手机用 APK）。**门卫（8792）跟着插件一起起，不需要额外装什么。**
2. **面板 →「QQ 接入」→ 打开小门**，抄下**口令**（地址不用抄，同机就是 `127.0.0.1:8792`）。
3. **机器人那边接上**（三选一）：
   - AstrBot：把 `astrbot/` 丢进 `data/plugins/`，填口令 → 完事
   - qq-bridge / 任意 MCP 宿主：挂 `qqbridge/mcp-bili.js`，口令**自动读**，不用填
   - 自己写：`POST http://127.0.0.1:8792/cmd`，带 `X-Bili-Token` 头

**机器人不在同一台机器？** 把 `127.0.0.1` 换成插件那台的局域网 IP（面板上会显示），并在面板里确认门卫绑的是 `0.0.0.0`（默认就是）。

## 先做这一步（三条路都要）

1. 打开刷B站面板 →「**QQ 接入**」页 → 点「**打开小门**」。
2. 抄下两样东西：
   - **口令**（打开小门时自动生成的一串字符）
   - **门卫地址**：同一台机器用 `http://127.0.0.1:8792`；机器人装在别的机器上就用「局域网地址」那条。
3. 决定权限：默认是「**只看不干**」（只能查，不能发）。想让机器人能干活（搜视频不算干活，发评论/发动态/野一轮才算），把「只看不干」关掉。

> ⚠️ 口令等于这扇门的钥匙。只发给机器人插件，别发群里、别截图。

## 1. 用 AstrBot（最省事）

见 [`astrbot/README.md`](./astrbot/README.md)：把 `astrbot/` 整个文件夹丢进 AstrBot 的 `data/plugins/`，填口令即可。

## 2. 用 qq-bridge / SnowLuma 或其它 MCP 宿主

见 [`qqbridge/README.md`](./qqbridge/README.md)：用 `qqbridge/mcp-bili.js` 这个 MCP 适配器，宿主就会多出 11 个 B站 工具（状态/搜视频/野一轮/发动态…）。

## 3. 自己写机器人（任何语言）

门卫就是普通 HTTP，不需要适配器：

```bash
# 查状态
curl -s -X POST http://127.0.0.1:8792/cmd \
  -H "Content-Type: application/json" -H "X-Bili-Token: <你的口令>" \
  -d '{"action":"status","args":{}}'

# 搜视频
curl -s -X POST http://127.0.0.1:8792/cmd \
  -H "Content-Type: application/json" -H "X-Bili-Token: <你的口令>" \
  -d '{"action":"search","args":{"q":"猫","n":5}}'

# 为所欲为野一轮（真发东西，会好几分钟）
curl -s -X POST http://127.0.0.1:8792/cmd \
  -H "Content-Type: application/json" -H "X-Bili-Token: <你的口令>" \
  -d '{"action":"wild","args":{}}'

# 看全部动作
... -d '{"action":"help","args":{}}'
```

返回值统一是 `{ok, reply, data}`：`reply` 是给人看的一句话，`data` 给程序用。

## 动作清单（门卫白名单）

| action | 干啥 | 级别 |
|---|---|---|
| `status` / `report` / `login` | 看状态 / 看今日日报 / 查登录 | 只读 |
| `watched` / `comments` / `posted` | 最近刷过 / 发过的评论 / 发过的动态 | 只读 |
| `search` | 按关键词搜视频 | 只读 |
| `run` / `dry` | 真跑一轮（会发评论） / 试跑（只挑不发） | 写 / 写 |
| `wild` | 为所欲为野一轮：自己挑视频、真评论+点赞+投币+发动态 | 写 |
| `dynamic` | 发一条图文动态（文字由调用方给） | 写 |
| `dm` | 查私信并按人设回（不重复回） | 写 |
| `stop` | 停掉正在跑的那一轮 | 写 |
| `retract` | 撤回最近几条自己发的评论 | 写 |
| `auto` / `auto_*` | 自动发视频（生成→审核→投稿）系列 | 写 |
| `help` / `ping` | 帮助 / 探活 | 只读 |

- **只读动作在「只看不干」模式下也能用**；写动作会被门卫直接拒掉。
- 改配置、看密钥这类动作**门里根本没有**——门卫不是万能代理。

## 常见问题

**必须装 DSH 吗？** → **不必须。** DSH 只是跑插件的一种方式；独立版（`node standalone.mjs`）和手机 APK 都自带同一套门卫（8792），一样能接 QQ。手机版、别人的电脑，只要装了插件就有门卫。
**「为所欲为」用不了？** → 插件本体要 **v0.3.78 以上**（门卫才有 `wild` 动作）；AstrBot 适配器要 **v0.3.5 以上**（才有 `bili_wild` 工具）；qqbridge 适配器要 v1.2 以上。
**「口令不对」** → 面板重开一次小门会让新口令生效；插件里填的必须是**当前**口令（qqbridge 适配器会自动读，不用手填）。
**连不上 127.0.0.1:8792** → 机器人和插件不在同一台？用面板上给的「局域网地址」。
**搜视频返回 0 条** → 先看机器能不能上网解析 `api.bilibili.com`（DNS 挂了会这样）；再看 B站 是否登录。
**野一轮没反应** → 面板「为所欲为」页看①开关有没有开②风控冷却中没③B站 登录掉没。
**想让它别乱发** → 面板把「只看不干」打开，或关掉「自动值守总开关」。
